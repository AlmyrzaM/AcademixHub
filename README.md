# Academix Hub

Modern, dark-mode landing page for Academix Hub built with React, Vite, Tailwind CSS, and Framer Motion. The site highlights tournaments, mentorship, and student success stories with animated gradients, glassmorphism, and responsive layouts.

## Development

1. Install dependencies (may require npm registry access):
   ```bash
   npm install
   ```
2. Start the dev server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
4. Preview the build:
   ```bash
   npm run preview
   ```

## Features
- Premium AI/research aesthetic with animated gradients and noise texture.
- Hero CTA for tournament applications and waitlist.
- Momentum metrics with animated counters and partner logos.
- Feature grid, how-it-works steps, audience tags, testimonials, and CTA banner.
- Responsive design with smooth hover states and micro-interactions.
